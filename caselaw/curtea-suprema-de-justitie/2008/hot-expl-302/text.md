# Hotărîrea explicativă a Plenului CSJ (Hotărîrile explicative ale Plenului), id 302, din 22.12.2008

```
HOTĂRÂREA PLENULUI
CURŢII SUPREME DE JUSTIŢIE A REPUBLICII MOLDOVA

Cu privire la abrogarea Hotărârii Plenului Curţii Supreme de Justiţie nr.12
din 09.04.1999 „Cu privire la respectarea legislaţiei despre utilizarea limbii în
procedura judiciară”, modificată de Hotărârea Plenului Curţii Supreme de
Justiţie nr.10 din 22.12.2008.


 În conformitate cu prevederile art. 16 lit. c) din Legea cu privire la Curtea
Supremă de Justiţie, în legătură cu pierderea actualităţii şi necesitatea racordării la
cadrul normativ care a evoluat în timp, Plenul Curţii Supreme de Justiţie

hotărăşte:

Se abrogă Hotărârea Plenului Curţii Supreme de Justiţie nr.12 din 09.04.1999
„Cu privire la respectarea legislaţiei despre utilizarea limbii în procedura
judiciară”, modificată de Hotărârea Plenului Curţii Supreme de Justiţie nr.10 din
22.12.2008.


Preşedintele Curţii Supreme de Justiţie                                   Mihai Poalelungi


Chişinău,
nr.38 din 04 decembrie 2017
```
